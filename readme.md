Создайте проект в Google Cloud Console:

Перейдите на сайт Google Cloud Console: https://console.cloud.google.com/.
Создайте новый проект или выберите существующий, в который вы хотите добавить API ключ.

Включите YouTube Data API:
В меню слева выберите "API и сервисы" -> "Библиотека".
Найдите "YouTube Data API v3" и включите его для вашего проекта.

Создайте учетные данные (API ключ):
Перейдите в раздел "API и сервисы" -> "Учетные данные".
Нажмите "Создать учетные данные" -> "Ключ API" -> "Ключ API для браузера или мобильного приложения".

Скопируйте ваш API ключ:
После создания ключа, скопируйте его. Обычно это строка из букв и цифр.
Теперь, когда у вас есть API ключ, вы можете использовать его для доступа к YouTube Data API.
